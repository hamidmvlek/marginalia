# Marginalia

A personal mind-map maker for books. Drop in a PDF, EPUB or text file and Claude draws a mind map of it.

- Runs entirely in the browser. Maps and books stay on the device (localStorage and IndexedDB).
- Uses your own Anthropic API key, stored only on the device and sent only to api.anthropic.com.
- The book is skimmed on the device first, so each map sends a few thousand tokens, not the whole book.
- Install on iPhone: open the site in Safari, Share, Add to Home Screen.
